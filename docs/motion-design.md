# Créer dans le studio Motion · Bêta

[← Les guides](README.md) · [Skills](extensions.md) · [Détails techniques](avance.md#motion-design-avec-effectcraft--bêta)

Le studio intègre **EffectCraft**, avec son propre chat spécialisé. Les rendus et exports dépendent des capacités du moteur ; tous les formats d’export vidéo n’ont pas été validés.

![EffectCraft avec une composition de démonstration et le chat Motion](images/mode-motion.png)

## Commencer simplement

1. Ouvre **Motion design** dans la barre de gauche et accepte le message de présentation.
2. Garde le mode **Simple**.
3. Décris un résultat concret : « Prépare un titre Aurora, avec une signature et une couleur vert menthe ».
4. Observe le résultat et demande les ajustements dans le chat.
5. Utilise **Lecture** et **Arrêter** pour contrôler la lecture.

Le bouton **Avancé** retrouve les outils complets de l’éditeur. Revenir au mode Simple ne crée pas un autre projet.

## Les tutos et les skills

**Tutos** propose des exemples guidés. **Préparer la demande** remplit ton brouillon : rien n’est envoyé avant ton action. Lire un tuto ou installer un skill ne lance pas l’IA ; envoyer une demande utilise le quota habituel.

![La sélection de skills pour le motion design](images/skills-motion.png)

Les skills EffectCraft accompagnent le studio intégré. Les skills Remotion concernent les vidéos créées en React dans l’espace Code. [Installer un skill](extensions.md).

## Enregistrer et reprendre

**Enregistrer** garde un projet modifiable dans le stockage local d’EffectCraft. Les médias et copies de projets suivent les fonctions de son menu File. Conserve une copie `.ecproj` et les médias pour un travail important.

Revenir au code conserve le moteur en mémoire. Rouvrir Motion permet de reprendre la composition pendant cette session. Ne confonds pas la sauvegarde du projet avec l’historique de conversation.

## Deux espaces indépendants

Code et Motion ont leurs modèles, conversations et brouillons. Termine la tâche et les demandes en attente avant de changer d’espace. Le chat Motion n’explore pas automatiquement le projet Code, même en Full accès.

Le bouton d’agrandissement du chat sert à se concentrer sur la conversation ; revenir à la vue normale retrouve le studio.
