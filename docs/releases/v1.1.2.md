# FranceStudent IDE · 1.1.2

**Lecture des images corrigée et vérification des mises à jour au démarrage.**

> **FranceStudent IDE est un projet de [EsteG7](https://github.com/EsteG7/francestudents-ide).** Cette version appartient au fork d’amélioration de [extraopaa](https://github.com/extraopaa). Le crédit de la création revient à EsteG7 et aux contributeurs d’origine.

## Les nouveautés

- **Images** : correction du prompt qui excluait à tort la vision, indication explicite des pièces jointes au modèle et validation des identifiants après téléversement.
- **Démarrage** : écran de chargement dans le thème de l’application, recherche des mises à jour à chaque lancement, bouton « Continuer sans attendre » et délai limité pour ouvrir l’IDE même si le service ne répond pas.
- **Saisie simplifiée** : suppression du sélecteur Agent / Plan, mode Agent direct.
- **Distribution** : l’installateur et les fichiers de mise à jour sont publiés sur GitHub. Le portable reste exclusivement local ; le workflow Windows respecte cette règle.

## Télécharger

| Fichier | Utilisation |
| --- | --- |
| **FranceStudentCode-1.1.2-setup.exe** | Installateur Windows x64 |
| **SHA256SUMS.txt** | Empreinte SHA-256 de l’installateur |
| **latest.yml** et **.blockmap** | Fichiers utilisés automatiquement par le mécanisme de mise à jour |

Ferme l’ancienne application avant l’installation manuelle. La version installée peut détecter la mise à jour si les mises à jour automatiques sont activées. Les exécutables ne disposent pas d’une signature d’éditeur reconnue ; Windows peut afficher un avertissement.

## Vérifications

- 26 tests ciblés validés pour les images, la compaction, les relances API et les tâches en arrière-plan.
- Sept tests ciblés validés pour les mises à jour et les formats de fichiers.
- Lecture réelle de deux images de contrôle vérifiée en chat puis avec le protocole Agent sur `gpt-5.6-terra`. Les autres modèles n’ont pas été vérifiés individuellement.
- Démarrage du paquet Windows, vérification publique des releases et accès à l’éditeur contrôlés.
- Bouton de passage et ouverture automatique après un service bloqué vérifiés dans Electron.

La vision dépend des capacités du modèle choisi. La version portable vérifie les mises à jour mais reste manuelle. Le parcours complet d’installation automatique depuis une version précédente reste à valider sur une machine installée.
