# FranceStudent IDE · 1.1.1

**Une conversation qui continue, un espace de travail plus complet.**

> **Projet original créé par [EsteG7](https://github.com/EsteG7/francestudents-ide).** Cette release appartient au fork d’amélioration de [extraopaa](https://github.com/extraopaa). Elle prolonge le projet original ; le crédit de sa création revient à EsteG7 et aux contributeurs d’origine.

## Télécharger

| Fichier | Usage |
| --- | --- |
| **FranceStudentCode-1.1.1-setup.exe** | Installation Windows x64 ; recommandé pour les futures mises à jour |
| **FranceStudentCode-1.1.1-portable.exe** | Utilisation sans installation ; mises à jour manuelles |
| **SHA256SUMS.txt** | Vérification des empreintes des exécutables |
| **latest.yml** et **.blockmap** | Fichiers utilisés par le mécanisme de mise à jour ; inutile de les ouvrir |

Ferme l’ancienne application avant de lancer cette version. Aucun Node.js n’est nécessaire. Un compte FranceStudent reste requis pour les modèles. Les exécutables ne sont pas signés par un éditeur reconnu : Windows peut afficher un avertissement.

## La nouveauté : compaction automatique

- À l’approche du budget de contexte, les échanges sont résumés automatiquement entre deux appels au modèle.
- Le résumé conserve les consignes, décisions, fichiers concernés, vérifications et travail restant.
- L’agent reprend sa demande sans confirmation ; le fil visible et les prompts en attente restent en place.
- Un refus explicite pour contexte trop long déclenche aussi une tentative de récupération.
- Si le résumé échoue ou reste vide, la conversation existante est conservée.

## Les améliorations regroupées dans ce fork

- **Agent** : file de prompts au-dessus de la saisie, Orienter, activité, plan de travail et commandes en arrière-plan.
- **Cockpit** : scripts du projet, sorties en direct, diagnostics, aperçu Markdown/HTML et outils locaux.
- **Éditeur** : formatage Prettier, comparaison, symboles, réglages et enregistrement automatique.
- **Web et extensions** : recherche autonome, captures, skills, profils, marketplace SkillsMP et serveurs MCP stdio.
- **Prise en main** : paramètres recherchables, connexion guidée et déconnexion explicite.

## Vérifications et limites

- 25 tests ciblés validés pour la compaction, les relances API, l’annulation et les pièces jointes.
- Démarrage du paquet Windows 1.1.1 et présence du code de compaction vérifiés.
- Seuil prudent : 80 % d’un budget estimé de 100 000 tokens, configurable avec `FS_AUTO_COMPACT_TOKENS`. Le service ne fournit pas la fenêtre exacte de chaque modèle.
- Le suivi du volume repart au redémarrage de l’application. La lecture d’images dépend du modèle.
- Mise à jour automatique pour la version installée, selon le réglage activé, à partir d’une release stable plus récente contenant tous les fichiers requis. Le parcours complet depuis une installation précédente reste à valider sur une future version.

> **Full accès permet d’écrire, supprimer et exécuter des commandes sans confirmation, parfois hors du projet.** Active ce mode uniquement avec des projets et outils de confiance.
